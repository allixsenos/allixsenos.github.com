Luka Kladarić

Software engineer in Zagreb. Below is the stuff I build outside work — mostly small services that watch something in Croatia and publish what changed, plus a few command-line tools.

Running

Public, maintained, updates itself on a schedule.

  1. standup.hr

    website

    Every Croatian stand-up show, by city and venue, with dates and times. No accounts, no ticket-shop noise. The whole catalogue is also a calendar you can subscribe to and a schema.org feed, so other things can read it.

  2. moviesoon.eu

    website · telegram

    Watches the Croatian cinema chains for what is coming out and, more usefully, for release dates quietly moving. Announces new titles, date changes and trailers, and publishes the upcoming slate as a page, an RSS feed and a calendar.

  3. Kazališni radar

    website

    The Croatian theatre programme in one place — city, theatre, show, performance dates and premieres — refreshed every morning.

  4. Korisni kalendari

    calendars

    The Croatian school year, public holidays, and the commemorative days and customs nobody can ever remember — as calendars you subscribe to once instead of looking them up every year. Croatian and English, and they work in Google, Apple and Outlook.

  5. Nespresso HR watcher

    telegram

    Reads the Croatian Nespresso catalogue once a day and sends one message when something actually changed: a new capsule, a price cut, a machine on sale, or a coffee flagged last-chance before it leaves the range for good.

  6. Claude Code releases

    telegram

    Claude Code ships several times a day and the changelog is a wall of bullets. This turns each release into one readable post in a Telegram channel, within the hour.

Tools

Things you install.

  1. cfntop

    go · tui

    top for AWS CloudFormation. Live view of every stack in a region, deployments in progress on top and expanded, ECS services showing task counts and why the failed ones failed. For watching a deploy without refreshing the console.

  2. cfnpeek

    go · cli

    The read-only half of the same problem: dump a deployed stack's resources, outputs, exports and events in whatever format the next command in the pipe wants. Cannot change anything.

  3. Claude Code plugins

    plugins · skills

    A handful of plugins for Claude Code. The one worth having is git-governor, which blocks the commands you never meant to run — amends, force pushes, reset --hard, commits straight onto main — before they happen rather than after.

  4. passwds.ninja

    website · extension

    Passwords you can read down the phone to someone. Generated in your browser and never sent anywhere. There is a Chrome extension too, for when the password field is right there.
